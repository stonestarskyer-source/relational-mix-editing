## 实现边界

1. 候选程序只计算纯增益的关系条件。底鼓与贝斯的频带选择、均衡渲染及音高／延音判断属于协议，当前没有相应执行代码或真实作品输出。
2. `listening_pass`仅接受一个目标评分，且只演示已给定输入的判断；S2中“多个目标同时通过”的通用实现尚待后续研究。函数测试不等于实际听评，也不表示已预注册。
3. 候选程序中的共同权限、技术通过状态是固定演算场景的前提，不是完整的运行时权限检查器。噪声、点击声和削波失真检查也未被自动实现。
4. 样本规划网格和统计规则是待实施的协议；没有受试者数据、功效模拟结果、显著性或效果优势。
5. 记录中的`shared_compression`键与“共享压缩”名称为历史兼容字段，指混合信号接受一次共同的总线压缩。它不证明Pedalboard与ReaComp数值等价。

实施或适配时发现新的研究问题应单独记录，不以未说明的代码“修正”改变已报道数值。任何扩大能力的实现须使用新版本，与原始演算分开。
